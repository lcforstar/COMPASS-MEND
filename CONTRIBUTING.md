# Contributing

Read NOTICE.md and preserve upstream and third-party attribution. Describe the
physical change, units, state/forcing ownership, and affected conservation gates.
Use the current production path as evidence. Keep changes focused and do not
relax tolerances or rewrite measurements to obtain a passing result.

Run the standalone smoke check for relevant entry/input changes and the focused
native checks required by the affected process. Report the scope actually run;
a few hours do not establish annual or cross-platform numerical equivalence.
Do not commit output, credentials, private server controllers or local paths.

# 长武冬小麦验证数据检索清单与使用方案

整理：Wenjie Liu。日期：2026-09-30。

**按用户最新范围，地上限定为冬小麦物候和以CoLM为参照的植被C/N分配，保留已有CoLM凋落物；其它部分继续使用COMPASS设置。工作重点是率定地下土壤水、碳、氮。SLA/Cdm、叶光学性状不在本轮修改或率定范围，LAI已有用户的Excel实测值，不列为缺失数据。** 当前生产配置实际读取`data/sites/changwu/canopy_measurements.csv`；后续只核对它与原Excel的年份、日期、DOY和变量口径。

本次补查了水分消耗、产量、地上干物质、组织氮、茎糖、光合、土壤呼吸和管理日期，按原文试验站、年份、品种及处理区分证据。产量、器官氮和物候资料用于检查固定的地上源汇是否合理，地下观测用于率定。此前茎糖和叶性状报告保留历史证据，不据此继续扩展地上过程。本次检索没有开展模型拟合；后续回退及验证结果由本轮范围回退报告另行记录，本文不预先声明通过。

上述记录已经存在，本轮不重建或替换。本次读取的2001年产量数值区域未标注原文出处，原始文献归属暂未核实，不能仅根据数据形似某论文就补上来源。原始单位未明确的量先保留状态；避免为比较而把未知基准改成假定基准。工作簿只读清单、2001年单元格位置和文件校验和见`existing_water_cn_inventory.json`。

文献优先补四类：生长季/分期ET与耗水，GPP/NEE和实际土壤呼吸，开花前后分器官氮及收获籽粒氮，残体去向和施肥操作日期。未发表的分量不从总量强行拆分：总ET不能唯一识别E/T，NEE不能唯一识别GPP/Ra/Rh，收获grain N不能唯一识别再转运贡献。

实测LAI继续作为冠层约束。其输入回放用于检查读取、插值和收获事件；水碳氮过程使用独立的水分、产量、组织氮与呼吸数据检验，不要求先增加预测LAI或叶性状模块。

**日期和管理来源。** 原文支持常见6月底至7月初收获，但当前输入LAI到零为2001-06-09。已有Excel的观测年/日期和收获记录优先，不能平移曲线。当前配置6月15日施肥，而已核长期论文描述9月播前基施，需核原小区操作记录。论文NPM不能仅凭输入数量与本项目NM文件名判为同一处理。郭胜利2001年学位论文题名已核，正文尚未定位，不代其核实“6月底”原句。

## 5. 地下率定优先次序与现有运行状态

只读核查见`outputs/underground_calibration_scope_20260930/README.md`和`scope.json`。`changwu_crop_lifecycle_20260930/annual`最后落盘为KT720/8760，`completed=false`，没有最终`result.json`，本次核查时没有活动MATLAB进程，原因未记录；不能称为正在运行、全年完成或已判定物理失败。首个非初态水/N观测在KT1464，故这个前缀尚不能提供动态观测拟合分数。历史五组measured-init年度8760h和六年两组54792h已经完成，可只读比较，但它们属于旧地上机制与各自冻结初态，不代替范围回退后的新基准。

1. **固定地上边界。** 按用户限定保留冬小麦物候、CoLM植被C/N分配和既有CoLM凋落物，其它COMPASS设置保留；回退实现与检查由本轮最终回退报告记录。之后冻结一条新配置身份的年度基准，覆盖播种、灌浆、单次收获和残体C/N去向。这样地下吸氮、凋落和管理源汇在参数比较中保持一致，不在率定地下时继续扩展地上。LAI实测与历史输出均保留。
2. **先率定土壤水。** 优先使用既有COMPASS候选`ks_profile_scale`和`vg_alpha_scale`，保持原剖面形状及冠层、根系设置。20—300cm水分每20cm一个标签；2000年8/10/12月每变量45条率定配对，2001年2/4月30条留出。按生长/休闲期和根区/深层列残差，并检查剖面储水及接受步实际水通量。土壤水分约束不足以独立拟合深于300cm的自由分层参数。
3. **建立一致的地下初态。** 起点θ、NH4、NO3和SOC有实测依据；DOC/DON是用户给定的试算初值，不以寻找不存在的2000 DOC/DON实测阻塞。未观测POC/MOC、DOC/DON、微生物、酶和有机N分库需预热及起点条件化，检验不同猜测值的记忆并记录C/N守恒衔接。不得直接用预热后DIN/SOC替代实测，也不得按步强制重置。
4. **地下N与碳低维联合率定。** DIN优先筛查现有尿素水解、硝化/反硝化Vmax、NH4吸附Kd与DIN弥散，挑选有效2—3轴；MEND已有低维候选CUE20、POM分解容量和DOM摄取半饱和乘子。若采用DOC/DON Kd轴，则按已有合同关闭DOM摄取半饱和轴，避免同一稀疏剖面同时拟合生成、摄取、吸附。既有包络为筛查先验，不是率定结论；CoLM凋落物和其它COMPASS过程参数先固定。DON初态影响NH4，因此最终DIN参数必须与地下有机库初态一致，不能更换预热初态后沿用任意初值上的最优参数。
5. **使用已有碳氮观测和留出年份。** 六年实际窗内SOC率定21行、DOC/DON各15行，2000起点SOC为audit；全清单SOC calibration=51包含窗前日期，不能混作有效样本数。2010表层MBC/MBN及2019SOC/DOC/DON/残体C独立报告，原SMB页已有MBN107.52mgN/kg但当前碳构建器未纳入MBN。DOC/DON提取方法与模型水相/吸附总量关系尚需核实，先分别报告、保持来源标记，不把未确认相态映射当作正式拟合通过。
6. **补充文献呼吸与耦合核查。** 生长季Rs比较根自养与地下异养合量；AOM还包括粪肥和残体，避免MEND/AOM重叠重复计数。气室地表逸出与产生率存在气体存量差时对齐实际地表通量或记录积分修正。PLOS原始Rs可检验数量级及温水/季节响应；不同年矿质N处理不能当当前NM年观测。配齐同年完整气象、管理和初态后才可另建独立试验，不自动增加额外地上参数。
7. **保持观测量和守恒量的口径。** θ读取accepted`Y.Theta_U`；NH4/NO3以干土质量上的溶解+相应吸附量匹配mg/kg，不直接用mg/L。碳采用同层段干土质量积分，SOC排除未反应AOM。1 t/ha=100 g/m²，1 kg N/ha=0.1 g N/m²，1 mg/kg=1 µg/g；DW→C和蛋白→N保留原文换算依据。水、总土壤+植物C/N闭合、收获移出和底部流失与观测误差分列；守恒通过不等于田间数量验证通过。

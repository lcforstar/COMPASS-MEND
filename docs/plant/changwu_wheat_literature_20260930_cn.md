## 当前处理最接近的长期与同年证据

郭胜利等的 NM 17 年平均籽粒产量为 **3.4 t/ha**，17 年累积作物吸氮为
**1067.5 kg N/ha**。两者分别是长期均值与长期总量；后者不是某一年吸氮，也不是
籽粒氮量。其他处理原值保存在 JSON，完整表与逐年结果尚未取得。
[期刊原始摘要](https://www.chinaagrisci.com/EN/Y2005/V38/I04/754)。

IAEA 报告的 2000–2001 季 Table IV（印刷页 81，PDF 第 88 页）给出普通平作 W、
覆膜垄作 WM1/WM2、休闲期免耕秸秆覆盖 WT 的籽粒产量。普通平作 W 为
**3.46 t/ha**。该季全部基施 N100、P₂O₅50 kg/ha，处理无当前 NM 猪粪；WM2 还
延后播种。因此它适合检验同季产量数量级，不能把这个单值作为 NM 的校准目标。
[IAEA 官方原文](https://www-pub.iaea.org/MTCD/Publications/PDF/te_1468_web.pdf)。

Hu et al. 的 2016 长期试验（DOI 10.1080/09064710.2016.1149215）方法列的是
CK/N/P/M/NP/NPM 六组，没有 NM。其品种和收获背景可参考，NPM 不应替代 NM。
[出版商原文入口](https://www.tandfonline.com/doi/full/10.1080/09064710.2016.1149215)。

## 收获期干物质与组织氮

Zhao & Si 原表 1/2 的转录包含三个生长季、四个施氮组合。籽粒氮库存可直接按面积
单位转换，与模型收获前 grain N 或本次 grain N export 比较；stem+leaf 的 straw
需要与对应的合并器官库存比较。该文没有把绿叶、直立枯叶和茎分别测定，不能用
合并 straw 数值单独验证 `N.leaf_senescent` 或 leaf C:N。原文的 grain、straw、chaff
采用 **60°C 24 h 至恒重** 的口径；此处不将其改成含水商品粮。
[出版商原始 PDF 索引](https://www.tandfonline.com/doi/pdf/10.1080/09064710.2015.1045933)。

访问边界保留：直接 PDF 和全文页请求返回 403，本次得到的是出版商搜索索引中的
原表文本，没有获得其 PDF 二进制。原表转录见 JSON 与
[缓存表数值转录](../../outputs/changwu_wheat_literature_20260930/Zhao_Si_2015_cached_table_numeric_transcription.txt)；其中 straw 表头的中间年份
在索引中重复为 `2011/2012`，本次保留原样，**未静默改成 2010/2011**。
取得原 PDF 前，该中间列不作为唯一年份的 straw N 观测。
对十二组 grain 数据做独立单位校核，`yield[t/ha] × N[g/kg DW]` 与表中
`grain N[kg/ha]` 在印刷舍入范围内一致；这个一致性检查不等于原 PDF 全面复核。

党廷辉等原文表 2 的五个 N 梯度、固定 P₂O₅90 的长期作物吸氮数据可检验 N 响应
范围。其肥料来源比例使用施肥与对照吸氮的差值法，**不是 ¹⁵N 示踪实测**。
不能用这些来源比例直接验证肥料示踪模块，也不能把发表年份当作当前生长季。
[期刊原文](https://www.plantnutrifert.org/cn/article/pdf/preview/10.11674/zwyf.2001.0208.pdf)。

## 茎糖再转运的直接长武证据与当前结构边界

Chen et al. 原文 Figure 3 和 Results（印刷页 21）显示：Changhan58 倒二节间果聚糖
在花后早期继续增加，T3 峰值为 **139 mg/g 干质量**；峰值时点为花后 24 d，随后
降低至成熟。图上端点读值标为近似值，正文报告的峰值保留为原文精度。
测量对象是去叶鞘倒二节间，不能直接换成整个茎的 g C/m² 库。
Table 2 的籽粒产量采用风干口径，未取得统一含水率说明，不能直接混用烘干产量。
[原始论文 DOI](https://doi.org/10.1080/01904167.2014.892989)，
[本次完整原文副本](../../outputs/changwu_wheat_literature_20260930/Chen_2015_fructan_primary.pdf)。

这支持“年度可溶性碳暂存—灌浆再转运”的方向，也暴露当前实现的结构检验缺口：
源码只在 phase 2 为茎 WSC 装库，进入 phase 3 即消耗，而原试验中早灌浆仍有净装库。
因此目前的守恒检查通过，不能升级为已重现整个长武灌浆时序。该论文没有为当前
0.30 分配、0.50/day 转运或直立枯叶 C:N65 提供对应率定值，本轮保持模型不变。

下一次结构实验应以开花、糖峰与生理成熟分开检查早期装库和后期净输出，并同时
追踪茎结构干质量、糖组成和器官 N；不要靠单个糖浓度下降率反推每日全株 C 流。
需要独立场地或品种时序检验，避免用同一曲线既率定又报告验证。

## 后续可执行的数量验证

- 对当前同年 NM，优先补齐收获 grain N 与分器官 N 库存，以及开花前后对应采样；
  用器官 N 差额和花后根系吸收共同检验再转运，不能把全部 grain N 都归给储氮。
  Mi et al. 的长武覆膜试验正提示花后吸氮会改变籽粒 N/蛋白，但其摘要相对效应
  不能替代当前绝对库存。
  [出版商研究](https://www.sciencedirect.com/science/article/abs/pii/S016719872200318X)。
- 氮量转换采用 `1 kg N/ha = 0.1 g N/m²`。只合计实际测得的 shoot organs，与模型
  相同器官或对应收获流比较，排除根和 mobile N；缺 chaff 独立槽位时明确模型映射。
- 干质量转换采用 `1 t DW/ha = 100 g DW/m²`。模型池单位为 C，比较 DW 还需要同批
  器官 C 质量分数；本次没有假定 C/DW=0.45 或 0.50，也没有凭空把 N 转成蛋白。
- 先按观测季、品种、施肥量/时机、覆盖、初态和水分条件建立对应关系，再定义误差。
  其他年份数据可做独立范围及结构检验，不强迫当前 NM 轨迹穿过每个外试验单值。

本次数据的获取与转录完成，不代表模型已经跑过上述田间数量验证。收获氮和过程
守恒是当前可先比较的量；绝对干质量产量与 WSC 时序还存在明确的口径和结构依赖。

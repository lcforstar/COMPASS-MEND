【一、模型身份】

COMPASS 的全称是 **Coupled Open Multiphysics Platform for Atmosphere–Soil Systems**，模型类别名称是 **The COMPASS Land System Model**。论文中将其定义为 “a process-based land system model for coupled energy, water, carbon, and nitrogen dynamics”。这里的 Open 表示开放式、模块化和可扩展的科学架构，不等同于已经采用开源软件许可证。COMPASS 源于 STEMMUS-SCOPE，但当前项目不能被简单视为原版 STEMMUS-SCOPE。它是面向下一代陆地系统模拟的多物理耦合研究平台，概念上与 CLM5 类陆面模型相近，同时吸收和比较 ClimaLand、Noah-MP、HYDRUS、DSSAT/CSM、DAISY 等模型的科学设计。

模型连接大气、植被/冠层、地表与深层土壤，主要过程包括：

1. 土壤水分：Richards 方程、Van Genuchten–Mualem 水力关系、非饱和导水率、根系吸水、深层渗漏、地表边界、地下水，以及可能启用的滞回和双孔隙过程。
2. 土壤热量：导热、对流/潜热项、冻融、多相热力学；地表能量边界以 docs/soil/compass_soil_water_heat_physics.md §2.8.1 / §5.7 为准（生产 atmospheric 匹配 G*，非钉皮温）。
3. 土壤气体：水汽、干空气、O2 和 CO2 的储存、扩散、对流及其与孔隙度、含水量、冰含量和温度的耦合。
4. 氮循环：NH4+、NO3-、尿素的迁移与转化，以及矿化、硝化、反硝化、固氮和植物氮吸收。
5. 冠层交换：辐射传输、叶片能量平衡、光合作用、气孔导度、蒸腾、湿叶蒸发、凝露、降雨截留和地表蒸发。
6. 植物过程：物候、LAI、碳氮分配、呼吸、LUNA/光合能力驯化，以及根—茎—叶 SPAC 水力过程。
7. 雪：ClimaLand 风格 bulk (S,S_l,U_s)、两 tile 通量、雪–土导热；与土柱经 §2.8.1 统一接口。
8. 数值求解：外层时间步、内部子步、Picard 迭代、必要时的 Anderson 加速、失败回滚、状态提交，以及守恒和收敛诊断。

当前模拟场景是中国黄土高原长武冬小麦（用户于 2026-09-15 明确）。按冬小麦任务核对物候、管理、根系及碳氮过程；历史苹果案例仅作有明确用途的历史参考，但模型目标是可配置、可跨 PFT 和可跨站点应用，不能把长武标定参数误当作普适常数。

【二、代码与架构情境】

项目根目录使用当前工作仓库，不以历史用户名或磁盘路径作为前置条件。

当前 MATLAB 源码主要位于 src/，采用包目录组织，包括 +atmosphere、+vegetation、+surface、+soil、+groundwater、+coupling、+interfaces、+step、+solver、+init、+io、+diagnostics、+equations 等。data/ 保存配置、强迫、初值和观测资料；tests/ 保存单元、回归、守恒、对照和诊断测试；docs/ 保存推导、设计、迁移记录和方法说明；PlotResults/ 与 tools/ 主要用于绘图、后处理、标定或辅助工作。

新的规范运行链是：

src/runCOMPASS.m 或正式独立入口 src/runWaterOnlySite.m
→ init.initialize
→ init.prepareRuntime
→ beginRun
→ 循环调用 runOneStep(model, kt)
→ finalizeRun

V1 入口和旧类隔离在 legacy/src，不属于生产 MATLAB 路径。分析受影响过程时核对用户实际使用的入口与调用链，并区分：

- 当前活跃并实际调用；
- 已实现但当前配置未启用；
- 只在测试或兼容层中使用；
- 旧版参考或已废弃；
- 文档规划但尚未实现。

当前架构应优先使用清晰的容器边界：

- model.built.Y：跨时间步的预报状态；
- model.built.p：参数和可重建的静态缓存；
- model.workspace 或等价容器：单步派生量与求解暂存；
- model.runtime：运行服务、时钟、I/O、控制和非物理运行信息；
- diagnostics/Registry 或等价容器：只写诊断与输出；
- pending/commit 机制：trial 计算和 accepted state 提交之间的事务边界。

不要在描述当前架构时把已删除的旧容器名称当成现行设计。旧变量和旧结构只可用于来源映射。跨步物理记忆应归属于明确的 Y.<domain> 状态；静态可重建内容属于 p；临时派生量属于 workspace/aux；诊断不能反过来成为隐式物理状态。

【四、科学判断原则】

涉及模型语义的修改，按受影响项核对：

1. 预报变量是什么？单位、符号和空间维度是什么？
2. 控制方程的守恒形式是什么？源汇项和边界通量如何定义？
3. 时间层分别是什么：上一步 accepted、当前 trial、迭代值还是下一步待提交值？
4. 该项与水、热、气体、氮、植物和冠层中的哪些过程耦合？
5. 极限情形是否正确：干土、饱和、冻结、无植被、无降水、夜间、零风速、高温或低温？
6. 修改后如何验证物理闭合、数值收敛和回归一致性？

不要把“程序可以运行”当作“物理正确”。优先检查：

- 水量、能量、碳、氮和气体质量守恒；
- 通量方向与正负号；
- Pa、kPa、MPa，m、mm，s、h、day，mol、µmol、kgC 等单位转换；
- 总压力、干空气压力、水汽分压和气体摩尔分数的区别；
- 液水、冰和气相占据孔隙后的有效孔隙度；
- 根系吸水与蒸腾需求、土壤水势和植物水势之间的一致性；
- 冻融潜热、液态水含量和总含水量的时间层；
- 边界通量究竟是瞬时率、时间步积分量还是累计量；
- trial 失败时是否完整回滚，诊断是否只在 accept 后写入。

对耦合偏微分方程进行推导时，先写真实残差，再解释线性化或微修正。最终闭合方程、系数定义和 Jacobian 应只依赖声明的主变量、已知上一时间层状态、参数和强迫；不要把未消去的中间状态导数藏在系数中。

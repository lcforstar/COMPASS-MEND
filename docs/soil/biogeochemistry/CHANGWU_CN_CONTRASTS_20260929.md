## 1. 本轮要回答什么

不是重新做 44 组水氮筛查，也不是开始六年碳率定。旧水氮结果保留。
问题是：深层 NH4 增加主要来自初始 DON 的可利用氮量、DOC/DON 摄取时间尺度，
还是 POC/MOC 向 DOC 的补给？这些机制可能同时存在，单一 NH4 拟合不能区分。

生产方程、边界和正式站点输入本轮均不修改。唯一评分修复是水相 DOC 后处理
从初始化专用 `Y.theta` 改读接受态 `mean(Y.Theta_L,2)`。它不改变积分轨迹，
也不决定哪一种 DOM 相应与实验结果比较。评分默认仍为 total，仅为既有兼容行为，
不是对实测口径的科学确认。

## 2. 初态与观测来源：已知和未解决项

- 当前模拟起点 2000-06-15；工作簿 `DOC和DON` 的第一组日期是 2006-09-15。
  20–300 cm 的初始 DON 与这组 2006 DON 数值对应（15 点最大差约 1.1e-9 mg/kg）。
  因而不能称为独立测得的 2000 初态，也不能同时作为独立终点验证。
- 初始 DOC 与 2006 或 2019 剖面均不相同。Git 首次提交 `0dfa85b` 已有现今
  DOC 剖面，例如 0 cm=245、20 cm=195 mg/kg；更早的测量/构造记录尚未找到。
  此提交中的 DON 原为 DOC/8；现今 DON 又经过改变。两种历史先验都不等于
  2000 年的直接 DON 测量。
- 初始输入注释称 `total DOM including sorbed phase`，并称水提取观测为代理。
  注释不是实验方法证据。现有工作簿的 mg/kg 单位不能独自判定应比较模型的
  全部 DOM、水相干土库存，还是实验操作定义的可提取部分。
- 旧文档曾使用 free DOM 干土质量口径，当前评分默认 total DOM，二者不一致。
  本轮同时保留两个量，不挑选更接近观测的一个作为“正确口径”。待提供原始测定
  方法、土液比、处理/采样与初始 DOC 来源后再确认正式观测算子。

## 3. 冻结设计

输出：`outputs/changwu_cn_contrasts_20260929`。
窗口：fresh KT=1..1464，即 2000-06-15 到 2000-08-15（首个非初始水氮观测日）。
年度配置及预分配不改，只积分此有界窗口；不冒称全年已经完成。

| ID | 唯一公开输入改变 | 检验含义与限制 |
|---|---|---|
| baseline | 无 | 当前参数基线，不继承旧检查点或历史酶播种 |
| don_half | raw.initial.don_mgkg ×0.5 | 初始可溶有机氮分配扰动；MON 相应增加，总有机氮不减少 |
| vg_half | soil.mend_vg_h ×0.5 | 摄取相关速率组；alpha 固定，Vm、死亡及休眠维持随原生派生关系改变 |
| ksdom_double | soil.mend_ks_dom_mg_g ×2 | 降低给定自由 DOC 下的摄取饱和程度 |
| vd_double | soil.mend_vd_pom_h ×2 | POM1/POM2/MOM 共享分解容量；不是只改 POC 或单独 MOC |

倍数是明确的机制扰动幅度，不是拟合结果或文献推荐范围。此次对全剖面施加同一倍率，
是为先区分机制，并不宣称识别了逐层参数。每次都从原始输入容器改变一项后，走完整
`checkSite → buildState → allocateWorkspace → initializeSoilAux → alignInitialThermalBoundary`
初始化链，不在运行中热修改参数。

冻结水力、无机氮、Kd、pH、酶初值、初始微生物比例、管理、微生物输运及 DOM 底边界。
深层硝化非零对照暂缓：需要可辩护的非零先验，不能先随意填数再以拟合改善为证。

## 4. 响应与判据

- 首个观测日全 15 深度 θ/NH4/NO3，以及各自 RMSE；深层 NH4 另报 240–300 cm
  四个观测标签的均值。只评价这一个日期，不称为年度校准/验证成绩。
- 每小时逐单元 DOC/DON 总量和水相干土库存、摄取、POM/MOM 补给、回收、AOM 输入、
  层间输运、微生物释 NH4/摄 NH4/NO3、硝化、MBC、活跃 C:N 和呼吸。
- 反应 C/N 残差 <1e-10 mg/g；重建 DOM 收支残差 <1e-8 μg/g；无机 N 原生累计
  残差 <1e-6 **μg N/cm²**。旧生产字段误标 mg，本轮保留数值门槛但明确真实单位。
- 独立 Python 后处理重算逐层积分收支、末态相平衡和 DON 初态分配守恒。
  深层反应的 FE 节点集合为 250/275/300 cm，半单元库存支撑 237.5–312.5 cm，
  不与上述四个观测深度的均值混为一个空间算子。
- 新鲜基线另与旧机制诊断 KT1464 的水、DIN、DOM 和主要微生物库作位级比较。
  这能验证该窗口的接口迁移等价性，不能外推为所有年度敏感性样本等价。

结果解释先看 DON→NH4 与 DOC 消耗是否同时改变，再看是否牺牲 NO3、MBC 或呼吸。
降低 NH4 并不自动证明参数正确。若仅改变 DON 初始分配就强烈改变 NH4，应先处理
初态不确定性；若 Vg/KsDOM 控制消耗速度，应优先给摄取速率组加约束；若 Vd 加倍
仍无显著供给，则不能靠轻微调 Vd 解释深层 DOC 缺口，也不能因此无限上调 Vd。

# 长武DOC–MBC率定实施规范

## 率定观测

0–20 cm NM处理目标：MBC = 574.58 ± 24.52 mg C kg⁻¹；MBN = 107.52 ± 2.08 mg N kg⁻¹；微生物量 C:N = 5.34 ± 0.13。基础呼吸与qCO₂只作辅助约束，图读值不承担主率定目标。

模型MBC观测算子：

\[
\mathrm{MBC}_{\mathrm{model}}(0\!:\!20)=\mathrm{BA}+\mathrm{BD}
\]

微生物残体（NECROMASS）不纳入MBC；SOC约束另行计算。

## 深度先验

只有表层MBC观测时，不为每一层建立独立自由参数。以表层率定参数为基准，地下层采用指数衰减先验：

\[
p(z)=p_{0}\exp(-z/L_p),\qquad z>20\ \mathrm{cm}
\]

其中 (p_0) 为0–20 cm率定值，(L_p) 为深度尺度。(L_p) 不是观测值，先作为敏感性参数；预热后只有在SOC/DOC剖面证据支持时才允许放开。该关系用于先验参数生成，不改变MEMC/MEND方程。

## 实施顺序

1. 以现有DOC初始剖面、SOC初始剖面和水氮率定状态初始化。
2. 运行自然周期预热，监测POC、MOC、DOC、BA、BD、NECROMASS及SOC残差；不得用MBC观测直接替换状态变量。
3. 以0–20 cm MBC为主目标，率定 `kd_doc_cm3_g`、`K_d`、`V_p`、`V_m` 和 `p_ep=p_em`；`m_r`先固定在源模型先验，不作为首轮自由参数。
4. 用MBN和C:N检查有机氮闭合；用基础呼吸和qCO₂进行辅助筛选。
5. 将通过表层约束的参数按深度先验扩展，重新预热；深层只在DOC/SOC剖面出现系统偏差时放开有限调整。
6. 通过年度SOC变化、DOC剖面、MBC范围、非负性和C/N守恒后，才进入正式多年率定。

## 率定目标函数

\[
J=w_C\left(\frac{\mathrm{MBC}_{m}-574.58}{24.52}\right)^2
+w_N\left(\frac{\mathrm{MBN}_{m}-107.52}{2.08}\right)^2
+w_{CN}\left(\frac{(C:N)_m-5.34}{0.13}\right)^2
+w_DJ_D+w_SJ_S+w_RJ_R
\]

其中 (J_D) 为DOC剖面误差，(J_S) 为SOC变化误差，(J_R) 为呼吸/qCO₂辅助误差。权重和可辨识性审查在预热后确定；没有观测支持的深层参数不允许通过过度自由度拟合。

## 率定准入门

- MEMC/MEND方程保持源代码形式；
- 总SOC、总有机氮及逐步C/N账本闭合；
- 0–20 cm MBC落在574.58±24.52 mg/kg观测范围附近；
- BA/BD均非负，且不能出现无界休眠库；
- DOC总量、水相DOC和观测算子定义明确；
- 深层衰减仅作为先验，不宣称为深层实测率定结果。

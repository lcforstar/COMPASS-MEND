## 2. 已核实的初始化事实

| 对象 | 当前活动代码合同 | 本方案处理 |
|---|---|---|
| SOC | `init.buildSoilCarbon` 从 `soc_total_mgkg` 插值至层中心，乘容重得到 g C/cm³ | 保留实测支持的总量约束；插值/外推不升级为逐层实测 |
| POC/MOC/MB/IOM | `organic_initial_pools.csv` 是分配先验 | 允许评估先验依赖，不能把所有层的比例独立自由率定 |
| DOC | 当前总量包含溶解与吸附相；`reserveInitialDOM` 从 MOC 扣除等量 C | DOC 已在 SOC 预算内，正式适配时不能再额外加一份或重复扣款 |
| DON | 当前总量包含溶解与吸附相；从 MON 扣除等量 N | DON 属于有机 N；不能从实测 NH4/NO3 扣除来“凑平” |
| NH4、NO3 | 当前 `nitrogen_input_phase="total"`，输入单位 mg N/kg 干土；Y 保存液相浓度 | 每组参数用自己的 θ、容重和 NH4 Kd 重建相态，约束的是总量而非固定液相数值 |
| 微生物 | C 为 top-down mg C/g；有机 N 为 bottom-up g N/cm³；含活动/休眠与移动/附着/滞留相 | 必须显式转换方向和单位，保留相/总量恒等式 |
| 有机 N 总量 | 现有 builder 从 C 分库及 C:N 先验生成，用户未说明有逐层 TN 实测约束 | 不声称 DON、MON 或全柱 TN 已被观测唯一确定 |

当前 SOC 观测算子来自 `tools/calibration/scoreChangwuCarbon.m:159` 和
`src/+diagnostics/writeStep.m:154`：

`SOC = POM1 + POM2 + MOC + MB + BD + ENZP1 + ENZP2 + EM + ENZN + DOC_total + IOM + NEC_C`

以上相加前统一为同一层、同一单位。POC、EP 是子库合计；MB/BD/ENZN 的三相
合计不能再重复相加。QOC 在当前线性平衡模式下是 DOC 总量的吸附分量，不能
作为另一份 C 加入。未反应 AOM（含地表/入土残茬和厩肥）不在当前 SOC 观测
算子内，但必须进入完整 C/N 收支账本。这个 SOC 算子是当前实现，不代表本次
已经独立核实实验室测定能严格排除所有新鲜入土有机物。

对无冰的当前初始化，节点总 DIN 的还原关系为：

`NH4_total_mgkg = Y.nh4 * (theta + rho_b * Kd) / rho_b`

`NO3_total_mgkg = Y.no3 * theta / rho_b`

改变 NH4 Kd 后，液相 Y.nh4 应相应改变；只要上述总量保持实测约束，就不是
改变了实测初值。正式实现还须检查接受态液水/冰相合同，不能将这些无冰公式
直接推广成所有冻融状态的库存算子。

## 3. 推荐路线：自然预热提供分配先验，独立构建实测约束 t0

### A. 冻结预热情景，不更换生产过程

- 正式 t0：2000-06-15 00:00；当前代理周期：到 2001-06-15 00:00，共 8760 h。
  实现从站点时间配置推导步数，不能再维护另一份硬编码日期/步数。
- 保留现行水热、冬小麦、PlantCN、施肥、AOM、MEND、DOM、微生物运移和开放
  边界；慢库加速关闭，不人为加酶、不重分配 MB 来绕过启动问题。
- 当前周期包含尿素 120 kg N/ha，以及厩肥 1326 kg C/ha、147.75 kg 总 N/ha；
  TAN 比例当前为 5%，是既有先验。每周期重放相同管理日历须明确叫代理情景。
  不把未来事件复制成已知历史记录；有真实前史时另建相应情景并更换身份。
- 在一个自然积分周期内，NH4/NO3/SOC 和其他状态都按生产方程共同演变；不按
  步或每年钳回实测值。观测只约束正式 t0，不是未来每一步的固定边界。

### B. 预热周期交接：同一实验连续保存物理状态

需要保留完整接受态、必要的根水/生理记忆及一致的收支历史，重建所有派生
缓存，再显式循环 forcing 和管理事件。不能只执行 `built.Y=carry`。

必须分别管理：真实累计预热时长、代理 forcing 相位、作物日历相位、诊断行号。
证明年末到下一周期首步没有重复/漏掉施肥、播种、收获，没有把皮温或根吸水
历史偷偷改成冷启动值。暂停恢复与自然周期换段是不同操作，不能混用。

### C. 正式 t0：新建壳，只导入白名单有机状态信息

推荐的首版算法是“观测条件化的分配先验”，不是自然平衡态原样接续：

1. 在本次候选参数下执行 fresh 初始化，取得当前日期、水热、植被及测量目标。
2. 从预热同相位末态提取独立有机 C/N 库和微生物相分配，不导入旧时间或累计量。
3. 为每层定义目标 `Cobs = rho_b * SOC_mgkg / 1e6`；IOM 当前为零且没有被预热
   辨识的依据，作为冻结先验处理。若未来非零，仍不得因数学投影自动改变它。
4. 设 `S` 为上述 SOC 算子中除冻结 IOM 外的独立 C 库之和，取
   `lambda = (Cobs - IOM_prior) / S`。要求目标剩余非负、S 正、所有值有限。
   对这些 C 库及配对有机 N 乘同层 lambda，保持各自 C:N 和三相比例；DON 也随
   有机分配尺度一致映射。若约束不可行，报告失败，不能裁成零或找 DIN 借 N。
5. 重建 POC/EP/PON 等合计与 DOC/DON 相态；不重新调用一次初始 DOM 扣库而双计。
   不能对整个结构体递归乘 lambda：累计量、别名、相合计、参数不是独立库存。
6. AOM 不参加 SOC 缩放。其同相位残留可作为单独的未测初态先验导入，但必须
   独立记录库存与来源，不能把未来那次施肥提前放入，也不能与 SOC 重复记账。
   地表残留同样不由 SOC 观测唯一确定。
7. NH4/NO3 使用本次参数重新 materialize 为实测总量对应的液相状态；水热/植被
   采用正式起点的初始化合同，不导入预热末年的全套 Y。历史残余尿素/颗粒肥等
   没有证据时保留现有 fresh 约定并标注，不将它们宣称为实测零。
8. 正式时间重新从 t0 开始；从最终初态重建各守恒基线，所有正式期累计量统一
   从零开始。保留预热原账本，另外保存逐层及全柱的初始化 C/N 调整量。

第 4 步是显式初始化假设，会改变预热末态的库存，也可能破坏刚获得的动力学
平衡。因此它只产生“受观测条件化的候选初态”，不能直接被称为已达平衡。
必须报告 lambda 的剖面、C/N 调整量、调整前后快库与首年响应；若条件化造成
明显启动冲击，不能通过反复投影或丢掉早期观测掩盖。届时改用有限历史过渡或
低维初态先验联合估计，另作设计比较，不偷偷改变方法。

当前矿质肥源 tracer 定义是正式期矿质施肥事件的来源。预热氮在新实验中属于
t0 背景：不把预热标签冒充正式期施肥来源；正式 tracer 与累计量重新初始化，
物理总 N 不因此减少。若今后研究历史施肥遗留，应另立历史来源定义而不是混用。

## 4. 怎样判断“预热够了”

先区分两种声明：

- **周期平衡预热**：相关 C/N、水热与植被状态及周期通量都满足同相位稳定。
- **有限预热/初态条件化**：快库和预测对起始猜测的依赖受到检查，但慢库仍有
  趋势或先验依赖。可以报告这种初始化，不得把它写成所有库达到平衡。

不预先承诺一年、三年或二十年一定足够，也不强迫实测 SOC 一定等于无限期
重复该年度管理后的平衡 SOC。IOM 等缺乏可辨识变化的库仍是先验。

### 所需的三组检查

1. **同一分支相邻周期**：逐层、逐独立库和微生物相比较，另报全年呼吸、
   矿化/固定、植被归还、DIN/DOC/DON/颗粒底部净出口及 gross 分量。
   不只比较全柱 SOC，不让不同层正负变化抵消。
2. **不同起点的记忆**：先用原猜测、较低与较高快库三种确定性起点。
   低/高方案拟取 DOC/DON 和微生物初始库存的 0.5/2 倍，差量分别在 MOC/MON
   内守恒重分配，保持测量总 SOC/DIN 不变；必须逐层检查供体充足及 C:N 可行。
   这是数值探针，不是实测不确定区间或概率样本。合并扰动只能发现依赖，不能
   分辨来源；如有依赖再只拆 DON 或 MB，不立即扩成另一套 44 点。
3. **条件化以后**：再次比较各分支正式 t0 的快库、全年轨迹和校准期响应。
   不能只证明原始预热末态相近，就假定投影后的正式运行不受初值影响。
   若 POC/MOC 分配仍未确定，须有另外的低维分配先验检查，不能由快库三分支
   宣称已经排除了所有慢库初值记忆。

现有默认相对门是 1e-3、最少三周期、连续两次通过，可以作为数值候选设置，
不是观测误差或论文通用标准。新实现须使用带单位的逐库绝对门加相对门；
绝对门先由零库存/小库存及短窗数值试验确定并写入 manifest，不能把当前不同
native units 共用的 1e-12 当成统一物理容差。正式发布前还须检查收紧数值门
是否改变科学结论。最大周期预算到达而未通过时记录 `not_converged`，不自动放行。

## 7. 与后续率定和论文的方法衔接

- 将初态视为显式函数 `I(p, observations_t0, prior, forcing_cycle, policy)`。
  改动 Ks、Kd、DIN 速率或碳过程参数后，旧预热末态不能无条件作为新参数的
  “平衡初态”。缓存精确命中全部身份才直接复用；相邻参数末态至多是 warm start，
  仍须通过本参数下的自然再调整和验收。
- 初期可在少量代表参数上检查初始化影响，控制成本；未经证据不能把所有
  BO 候选都固定用同一个错误平衡态，也不需要一开始就对所有层独立率定。
- 择参只使用既定校准目标；验证数据不用于选择初始分配/预热年数。若已经
  反复查看并据此设计，应如实称开发期留出检验，不包装为完全盲测。
- 水氮先率定、碳后率定是实用顺序，不表示单向无反馈。碳动力学/有机 N 初态
  改变后必须复查水氮响应；有必要才作有限交替调整。
- 论文可使用“观测约束初始化、周期代理驱动预热、初值依赖检验、分阶段多目标
  率定”等名称，但只报告实际完成的阶段。不要写“预热得到了实测 DOC/DON”。

# 长武原生 BGC 参数率定准备与准入门

日期：2026-08-29

## 1. 当前结论

当前仓库已经具备原生 AOM–DOM–MEMC/MEND–BIOPARTICLE 参数接口、守恒测试和
短期工程运行能力。唯一的长武冬小麦实测数据源是
`data/sites/changwu/NM冬小麦实测.xlsx`。该工作簿可以约束水分、矿质氮和总 SOC，
但不足以独立辨识完整的 DOM、MEMC/MEND 和 BIOPARTICLE 参数组。

逐参数来源、郭胜利论文可用边界和已完成的先验归一化见
`CHANGWU_BGC_PARAMETER_SOURCE_AUDIT.md`。MEMC 时钟已审计并锁定为 day / d⁻¹，
证据见 `MEMC_TIME_BASIS_AUDIT.md`；时钟不再是阻断项，但参数尚未率定。

## 3. 参数分类

### 3.1 固定结构参数

以下参数暂不参加场地率定：`respiration_fraction`、`q10`、`frozen_q10`、
`smpmax_mm`、`smpmin_mm`、`depth_efolding_m`、`p_ep`、`p_em`、`r_ep`、
`r_em`、`Q_max`、`dd_beta`。它们用于冻结当前 CoLM/MEMC 方程结构；若要调整，
必须作为单独的结构敏感性试验。

`reaction_substep_s`、`mend_substep_s`、`transport_substep_s` 等是数值控制，
只能做时间步收敛检查，不得用来拟合观测。

### 3.2 可由当前实测约束

- 水力参数先用水分剖面校准并保留 2001 年独立验证日期；
- 硝化容量、反硝化容量和 NH4 吸附在水力门通过后，用 NH4/NO3 剖面联合率定；
- AOM/MEMC 的低维组合参数可以用 1986–2019 表土 SOC 趋势和
  1998/2000/2019 SOC 剖面联合约束；必须限制自由参数数量，不能一次释放全部速率。

### 3.3 可率定但当前实测不足

| 组 | 参数 | 最低观测需求 | 当前状态 |
|---|---|---|---|
| AOM | 分别辨识 `k_litter_1d`, `k_straw_1d`, `k_manure_1d`, `doc_leach_1d` | 材料质量损失、CO2、DOC 脉冲 | 总 SOC 只能约束低维组合 |
| DOM/DON | `kd_doc_cm3_g`, `kd_don_cm3_g`, `dom_disp_cm`, DON MM 参数 | 吸附/穿透试验、DOC/DON 与 NH4 动态 | 缺少长武直接观测 |
| MEMC | `vp_1d`–`mr_1d` | POC、MOC、DOC、MBC、呼吸和酶的联合时间序列 | 不可辨识 |
| MEND | 活跃比例与休眠维持 | 活跃/休眠微生物量与呼吸 | 不可辨识 |
| BIOPARTICLE | 附着、解吸、截留、弥散 | 微生物示踪或柱实验剖面 | 不可辨识 |

### 3.4 初始化先验

`CN_POC0`、`CN_MOC0`、`CN_QOC0`、`CN_MB0`、`CN_EP0`、`CN_EM0`、
`CN_NEC0` 和 `active_fraction_initial` 首先属于状态初始化先验。只有获得相应
库分级、MBC/MBN 或活跃/休眠观测后，才允许与动力学参数联合估计。

## 4. 分阶段率定顺序

1. **冻结水热驱动**：先用含水率、温度和水量闭合验收环境标量，不调整 BGC 参数。
2. **矿质氮率定**：在水力门通过后，用 NH4/NO3 的校准与验证日期约束无机氮反应和输运。
3. **SOC 低维率定**：用 1986–2019 表土序列与三期 SOC 剖面，先筛查一个共享 AOM
   强度和一个慢库/MEMC 周转组合；不得同时释放全部 BGC 参数。
4. **DOM/DON 独立率定**：获得吸附、穿透或剖面数据后确定 Kd、弥散和 DON 氨化。
5. **MEMC/MEND 联合率定**：以 POC/MOC/DOC/MBC/MBN、呼吸和酶为多目标，限制
   参数维数并保留独立验证时段。
6. **BIOPARTICLE 条件率定**：只有获得微生物迁移/示踪数据时启用；否则保持先验并做
   不确定性情景，不宣称场地率定。
7. **参数冻结后预热**：普通长预热建立稳态真值，之后才开发和验收周期加速。

## 5. 每个候选参数集的硬门

- 所有 C/N 状态有限且非负；
- 小时与年度 C/N 守恒门通过；
- checkpoint 连续运行与重启等价；
- 数值子步减半后关键输出稳定；
- 校准与验证数据严格分离；
- 不以当前模型输出、旧 DAISY 稳态或咸阳代理数据同时充当校准值和验证真值；
- 未被观测约束的参数必须报告为先验或不确定性范围。

## 6. 下一项可执行工作

在不等待新增实验数据的情况下，可以先建立“工程灵敏度筛查”：一次只改变一个参数组，
运行短窗口并检查守恒、非负性、数值稳定性和输出响应方向。该筛查用于缩小后续率定范围，
不产生最终参数，也不触发正式长预热。

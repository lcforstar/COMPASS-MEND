# 长武实测水分、无机氮与 SOC 初态：映射修复

Editor: Wenjie Liu; Date: 2026-09-29.

## 用户约束与实际修改

用户明确：水分、NH4、NO3 和 SOC 初始值均为实测；DOC/DON 是任意给定的起始猜测，其他未观测有机库需要后续预热。本轮不修改实测输入文件，不把未观测库改称实测，不启动年度预热或正式率定。

新增 `init.conditionMeasuredSoilInitialState`，在完整初始水热辅助量/底部热条件处理后、运行时钟开始前执行。长武当前为正温、单土柱、体积含水量输入：先将实测 theta 线性插值/外推到网格节点，再反演实际生产水力端点内核的节点水头，使相邻半层控制体加权总含水量匹配该目标。反演包含实际温度修正和分层保水性质，不以一侧层的普通 VG 反算冒充最终初态。层交界两侧含水量仍可不同，不强行钉成相同值。

水分输入超出活动保水曲线可行范围时明确拒绝，不用另一含水量或场持水量替代。重建初始能量和辅助量后，再用氮求解器保存的初始有效液态水容量换算实测总 DIN。浓度换算和观测回算共用 `soil.nitrogen.observationProfile`：半层厚度加权液水/吸附容量除以同一控制体干土质量，与逐层梯形库存积分一致。

新流程已接入 `init.initialize`、水氮样本构建器、碳样本构建器和实测约束有机库初态接口。SOC 分库总量及现有 SOC 观测算子未改动；当前 DOC 总量已包含在 SOC 预算内，不能额外增加一份。实测剖面的网格插值/外推不成为新的逐层观测。

该新水分条件化目前只声称验证了长武正温单柱。冷初态、实验室、区域/多柱和非体积水分输入保留原行为并显式报告未应用；不声称这些路径也满足本轮实测约束。

## 诊断、评分与重启

门评分、旧基准评价的回算函数及生产 DIN 输出使用同一接受态 N 观测算子，不再根据诊断总量是否为零选择不同公式。该观测量延续溶解加平衡吸附态定义，**不含冰中封存 N、未反应肥料颗粒或尿素**；这些仍在物理守恒账本中，不被删除。冻土采样的实验提取口径仍需专门核对，不能由本次暖土验收自动证明。

内部 `NH4_total/NO3_total` 两槽及其 pH 动力学消费者未修改；输运、硝化反硝化、边界和生产容差也未修改。本轮改变的是零步初始化及观测诊断合同，而不是重新定义反应模型。

水氮/碳 runner 向评分器传递实际样本的未运行初态。新 checkpoint 保存层厚、容重和 NH4 缓冲容量供评分核验，避免 NH4 Kd 样本误用基准参数回算。超出末个接受 checkpoint 覆盖时间的观测标记排除，不用末态冒充后续观测日期。

新初态协议写入 checkpoint 兼容签名；旧协议 checkpoint 不能静默恢复为新初态试验。该签名标记不是完整源码/驱动哈希；campaign 和周期交接仍各自承担其原有身份检查。

## 验收

新水分/DIN/SOC 测试 16 组 PASS：基准、确定性、缓存重建、样本基准逐位一致、alpha/Kd 的 0.5 和 2 倍边界、非均匀层厚/端点跳变库存、观测相态排除、弃用诊断槽不参与回算、非法状态/不可行测量拒绝、dissolved 单位兼容、两小时积分/输出一致、旧协议恢复和积分中重新条件化拒绝、评分时间覆盖与样本参数不符拒绝。

证据：`outputs/measured_soil_initialization_20260929/20260929_204123/verification.json`。

| 零步基准误差 | 最大值 |
|---|---:|
| 水分 [m3/m3] | 5.5511e-17 |
| NH4 [mg N/kg] | 8.8818e-16 |
| NO3 [mg N/kg] | 7.1054e-15 |
| SOC [mg C/kg] | 3.6380e-12 |
| DIN 库存差 [ug N/cm2] | 不超过 1.8190e-12 |

原有有机库条件化 29 组回归也通过，最长连续窗口 24 h，共 48 个已接受测试小时，直接积分和断点恢复状态逐位一致：`outputs/measured_initialization_20260929/20260929_203618/verification.json`。

独立零步映射诊断验证生产协议已生效，原 NH4/NO3 库存相对目标差现为约 1.11e-16 / 2.68e-16：`outputs/din_mapping_audit_20260929/20260929_204242/verification.json`。其中旧初始化/旧评分公式仅作为历史比较，不再是当前生产算子。

首次新测试已完成积分但因测试脚本采用未确认的工作簿查找规则失败；已改为正式筛查入口的确切工作簿路径，重跑通过，保留失败目录 `20260929_203902`。没有改观测值、放宽容差或跳过检查。

周期交接回归 PASS，共 10 个已接受测试小时，普通运行及周期重放的 checkpoint 恢复均逐位一致，7 类非法交接被拒绝：`outputs/bgc_cycle_carry_check_20260929_204002/verification.json`。旧两小时参考与新实测初态协议不具逐位可比性，明确标记协议不同，不覆盖历史参考。两小时技术周期不用于声称年度预热收敛。

## 历史样本与下一步

站点四个实测/初态输入和已完成桥接 campaign 的五个 SHA256 均未改变。历史结果保留为旧协议证据，不宣称白跑，也不自动将其标为新协议结果。

观测算子变化可以从已有 checkpoint 单独重评分，但改变初始物理状态后的新轨迹不能靠重评分获得。下一步应先用新协议做基准及少量关键参数点的版本对照，检查门值和排序是否改变，再决定补算范围。

# DOC 运输的分子扩散与曲折度处理核查

Editor: Wenjie Liu  
Date: 2026-10-14

## 2026-11-03 勘误：同一浓度梯度下的分子扩散导度

原文第 1–4 节将 DOM 的 `θ·D₀` 与 DIN 的 `f_w·D₀` 直接比较，漏掉了 DIN 组装至土体积通量时还要乘的 `θ`。在实际传入有限元的 `Dsh` 中，物理分子项为 `θ·D₀·f_w`，`f_w=θ^(7/3)/θ_s²`。等 D₀、等含水量且 `0<θ≤θ_s<1` 时，DIN 与 DOM 的分子导度之比等于 `f_w<1`，原文所述“湿期反转”及以此为依据的统计解释不成立。冻结 30 号 2006 年 9 月 0–20 cm 的 14,400 个单元小时中，按单元平均水量算得 `f_w` 为 0.276–0.633。原检查点中 DIN 有效双端水量、Dif、Dsh 和实际数值开关也已独立核回。降低 DOC/DON 共用的扩散系数后，连续计算使该月 20 cm 的 DOC 净下移量增加 11.21%–12.43%，140 cm 的变化方向相反。下文保留原核查口径、数字和归属。[修正后的推导、开关与长武连续实算](../../../data/verification/cand30_doc_D0_20261103_01/分子扩散、曲折度与30号连续通量.md)

## 1. 结论摘要

1. **模型内液相溶质扩散有两套互不相同的处理。** 氮素路径带有 Millington-Quirk 曲折度修正
   `f_w = θ^(7/3)/θ_s²`；DOM 路径（以及复用同一算子的生物颗粒路径）只用裸含水率 `θ`。
   同一土壤、同一孔隙水中的两种溶质，有效扩散系数相差一个随含水量变化的因子。
2. **该差异不是单向的。** 令两式相等得交叉含水量 `θ* = θ_s^(3/2)`。长武表层 `θ_s = 0.416`，
   故 `θ* = 0.268`。含水量低于 0.268 时裸 `θ` 高估扩散，高于 0.268 时低估。
3. **在本次存档时段的实际含水量下，DOM 路径多数时间偏高、少数时间偏低。** 0–20 cm 共
   158,400 个层-小时中，82.5% 的样本 MQ 因子小于裸 `θ`（DOM 偏高），17.5% 相反。比值中位数
   0.861，p1 0.385，p99 1.284。
4. **因此不能把表层 DOC 亏损简单归因于"扩散系数偏大"。** 曲折度缺失带来的偏差有季节方向性：
   干期高估、湿期低估，两者在年尺度上部分抵消。
5. 另有两处**同族但性质不同**的不一致，已在第 5 节列出，本次不下结论。

## 2. 各路径的处理对照

| 路径 | 实现位置 | 有效扩散 | 是否有曲折度 |
|---|---|---|---|
| DOM（DOC/DON 水相） | `src/+soil/+dom/transportConservative.m:106` | `θ_face · D₀` | 否 |
| DOM 边界导度 | `src/+soil/+dom/boundaryCoefficients.m:30` | `θ · D₀` | 否 |
| 生物颗粒（可动微生物） | `src/+soil/+microbe/bioparticleTransport.m:202-205` | 调用 `soil.dom.transportConservative` | 否（继承上行） |
| 无机氮运输 | `src/+soil/+nitrogen/+transport/soluteDispersion.m:65` | `f_w · D₀ · e_T` | 是，`f_w = θ^(7/3)/θ_s²` |
| 无机氮根系吸收 | `src/+soil/+nitrogen/+root_uptake/nitrogenUptake.m:160` | 同上 | 是，注释自述"与 soluteDispersion 一致" |
| 气相（水汽、热） | `calculateVaporVariables.m:60`、`calculateThermalLiquidDispersion.m:69` | `θ_gas^(7/3)/θ_s²` | 是（气相，属另一相，非本次问题） |

DOM 的三条实现（运输、边界、生物颗粒）共用同一个算子，因此**实际上只有一处需要修改**。

原始代码：

```matlab
% transportConservative.m:103-107
thetaFace=max(0.5*(theta(face)+theta(face+1)),0);
distance=0.5*(dz_cm(face)+dz_cm(face+1));
dispersionFace=0.5*(dispersion_cm(face)+dispersion_cm(face+1));
dispersive=thetaFace*diffusion_cm2_s+dispersionFace*abs(qFace);
```

```matlab
% soluteDispersion.m:65
fw = Theta_LL.^(7/3) ./ Theta_s'.^2;
```

按 Millington & Quirk (1961, *Trans. Faraday Soc.* 57:1200)，液相有效扩散应写作
`D_eff = θ^(7/3)/θ_s² · D₀`。DOM 路径下的 `θ` 是这一因子的经典简化替代，在近饱和时才与
MQ 接近一致。

## 3. 两式差异的解析形式

令 `θ^(7/3)/θ_s² = θ`，得 `θ^(4/3) = θ_s²`，即交叉含水量

```
θ* = θ_s^(3/2)
```

`θ_s = 0.416`（`data/sites/changwu/soil.csv` 表层 0–20 cm 行）时 `θ* = 0.268`。

| θ | MQ `f_w` | 裸 θ | 比值 MQ/θ | 含义 |
|---:|---:|---:|---:|---|
| 0.100 | 0.0268 | 0.1000 | 0.268 | 裸 θ 高估 3.7 倍 |
| 0.150 | 0.0691 | 0.1500 | 0.461 | 高估 2.2 倍 |
| 0.207 | 0.1460 | 0.2067 | 0.706 | 高估 1.4 倍 |
| 0.250 | 0.2275 | 0.2500 | 0.910 | 基本一致 |
| 0.307 | 0.3671 | 0.3069 | 1.196 | 低估 1.2 倍 |
| 0.350 | 0.4989 | 0.3500 | 1.425 | 低估 1.4 倍 |

## 4. 与本次存档实际含水量的对照

`runs/C01/model-output/segments/` 前 11 个分段、0–20 cm 全部层-小时（158,400 个样本）：

- 含水量：中位数 0.2397
- MQ 因子中位数：0.2063
- 比值 MQ/θ：p1 = 0.385，中位数 = 0.861，p99 = 1.284
- **82.5% 的样本 MQ < 裸 θ**（DOM 路径扩散偏大）
- **17.5% 的样本 MQ > 裸 θ**（DOM 路径扩散偏小）

即：在本次运行的含水量分布下，缺失曲折度使 DOM 有效扩散在多数时间被高估，但高估倍数是湿度
依赖的（干期可达 2–3 倍，湿期反而偏小），并非一个固定倍数，也不能用"除以某个常数"折算。

**这与"把 D₀ 直接降到 2e-6 cm²/s"不是等价操作**：下调 D₀ 是全年均匀缩放，而补上曲折度是随
含水量变化的再分配。两者对表层 DOC 亏损的年际影响可能不同号。

## 5. 同族但本次不下结论的观察

核查中另见两处不一致，均记录在案但不属于本次核查结论：

1. **氮素与 DOM 使用了不同的弥散度。** `soil.csv` 中 `disp_cm` 取值为 2.2824、4.2189、
   4.5649 cm（按层各异），而 `dom_disp_cm` 与 `microbe_disp_cm` 全部 18 行恒为 4 cm。
   氮素路径的弥散度是逐层变化且与 DOM 不同的物理量。
2. **`difnh4_cm2d = difno3_cm2d = 48.96`（cm²/d）的量级需要确认口径。** 该值折合
   `5.667e-4 cm²/s`，比 DOM 的 `5e-5 cm²/s` 大 11 倍；而硝酸盐/铵在自由水中的扩散系数约为
   `1.9e-5 cm²/s` 量级。若该列本就是**土壤有效扩散系数**（HYDRUS 系惯例），则
   `soluteDispersion.m:65` 再乘一次 Millington-Quirk 属于重复计入曲折度。本次未追溯该列的
   生成链路，故只列为待查项，不判定为缺陷。

## 6. 待定事项

本核查按要求先出说明，不修改任何代码。是否给 DOM 路径补上曲折度修正，等
`outputs/dom_transport_sensitivity10_sixyear_20261014_01` 十组六年结果出来后一并决定。

需要区分的两个独立问题：

- **D₀ 的量级**：当前 `5e-5 cm²/s` 相对文献 DOC 值（Ota et al. 2013 约 `1.23e-6 cm²/s`；
  Lead et al. 2000 腐殖酸/富里酸水中扩散约 `2–3e-6 cm²/s`）偏高。这由 C01/C04/C07 与
  C02/C05/C08、C03/C06/C09 的比较回答。
- **曲折度处理**：是否把裸 `θ` 换成 `θ^(7/3)/θ_s²`。这不是缩放 D₀，而是改变其湿度依赖性。

两者不可互相替代，也不应在同一轮里同时改动。

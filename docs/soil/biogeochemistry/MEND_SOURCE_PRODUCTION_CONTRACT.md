本文说明MEND和COMPASS各自负责什么、每小时如何交换信息，以及正式耦合采用哪些处理。它是开发和使用模型时共同遵守的接口约定。测试结果放在单独的验收文档中。

## 一、MEND负责什么，COMPASS负责什么？

接入的是MEND的**有机碳氮与微生物反应部分**。土壤水分、温度、氧气、无机氮、根系和层间运输仍由COMPASS计算。

| 要解决的问题 | 由谁负责 |
|---|---|
| 每层土壤有多湿、多热，能获得多少氧气？ | COMPASS |
| 外界有多少碳氮进入土壤，进入什么深度？ | COMPASS的输入、植被和管理过程 |
| 有机质如何分解，微生物如何生长、呼吸和休眠？ | 接入COMPASS的MEND反应部分 |
| 微生物吸收多少无机氮、释放多少氮？ | MEND计算反应需求与释放，COMPASS提供并约束可用库存 |
| 无机氮如何硝化、反硝化、吸附和迁移？ | COMPASS |
| 溶解有机物和微生物如何在土层间移动？ | COMPASS |

也就是说，MEND计算每层土壤内的生物化学反应，COMPASS提供反应环境，并把不同土层和其他过程连接起来。

**pH 响应由配置显式选择。** `[microbe].mend_ph_response = false` 时，POM1、POM2 和 MOM 三条酶解支路的 `fpH = 1`，保留各自 Arrhenius 温度项和水势响应。设为 `true` 或省略此键时，保留源 `fpH0` 钟形响应及既有宽度、最适值修正参数。长武本轮设为 `false`，作为关闭 pH 域外响应的耦合情景；这不是对源模型 pH 曲线适用范围的独立验证，也不是重新率定酶解速率。

## 二、每小时怎样计算？

1. **准备环境和输入。** COMPASS计算本小时的土壤环境，根据已开启的过程准备施肥、凋落物等输入，再计算溶解有机物的层间运输。
2. **分配可用氮。** 先为根系预留氮，再确定微生物可利用的浓度和库存。
3. **计算有机反应。** MEND计算各层有机库、微生物和酶的变化，以及呼吸和氮的吸收释放。
4. **检查氧气和运输。** COMPASS接收本小时 MEND 呼吸和无机氮源汇，计算运输与无机氮反应，并检查供氧是否可满足这些源汇；不可行时拒绝候选，不缩放 MEND 反应量。
5. **通过检查后一起保存。** 整个小时计算成功后，碳、氮、氧和土壤状态才一起更新。失败时退回小时初状态，不重复施肥、不重复扣氮、不推进时间。

当前MEND反应按一小时更新一次。水热计算即使在一小时内分成多个小步，也不能重复执行整小时的生物反应。

断点还需要保存会影响下一小时的运行记忆。目前明确包括上一小时已接受的根系吸水通量；只保存碳氮库和土壤状态并不足以保证重启一致。缺少这项记录的旧断点必须标明无法保证精确续跑。

## 三、初始碳氮和外部输入怎样处理？

**长武使用 MEND 动力学吸附/解吸（2026-10-23 用户指定恢复）。** `[dom].sorption_model="mend_dynamic"` 下，输入的 D/Q 及 DON/QON 分别保留。DOM 唯一所有者保存总量和独立吸附库，D=总量−Q；MEND 反应更新 D、Q 后写回总量和 Q，不使用 `soil.csv` 的 DOM Kd 重新分配。兼容字段 `soil_microbes.QOC` 与 `soil_organic.QON` 为零，仅表示不重复持有同一库存。

源 `fAds` 的小时顺序保留：先计算 D 的微生物摄取，再以剩余 D 计算吸附与 Q 的解吸，使用源 Kads、Kdes、Qmax 及源供体限制；解吸产生的 D 不提前提供给本小时已经完成的摄取。伴随有机氮沿实际碳转移配对，吸附/解吸不直接生成无机氮。2026-09-16 曾按用户要求采用 COMPASS 线性平衡；该选择保留在显式 `linear_equilibrium` 兼容分支，已不用于本轮长武运行。

**正式站点由初始剖面 SOC 与 `organic_initial_pools.csv` 构建一次分层有机初态。** 长武当前使用用户指定的细分先验，不在运行时读取外部有机初态 MAT 覆盖；分库不是逐层实测。动态模式要求明确的独立 D/Q 先验，不能从 Kd 和含水量猜测 Q。旧四列粗分库格式仅在其原有兼容路径使用。也不能为了对齐MEND，把上部土层的平均含量自动复制到整根5米土柱。

外部输入由COMPASS统一处理。必须明确每次输入的碳氮数量、进入的库、施加深度和时间，且每一份物质只计入一次。例如，COMPASS已经加入一份肥料后，MEND不能再加入同一份肥料；肥料中的铵态氮和有机氮也要分开计算。

这里要区分两种时序：

- 正式COMPASS路径在调用微生物反应前，由上游过程准备输入。
- 独立MEND对照按照源模型的小时末输入顺序运行。

此前对齐源小时末输入的试验程序，没有自动成为正式模型的输入功能。

AOM 指新鲜加入、尚未完成分解的有机物。植物凋落物、粪肥有机部分和秸秆分别先进入 `aom.litter`、`aom.manure`、`aom.straw`，不在投放阶段直接写入 POM 或 DOM。叶片与细根按各自 metabolic/cellulose/lignin 比例入库；修剪和木质/粗根枯死进入 CWD。叶片及地上木质返回顶层单元，根系按配置深度权重分配；管理事件保留地表或混入土层的放置方式。肥料 TAN 单独进入 COMPASS 无机 NH4 账本。

**PlantCN 关闭时可单独指定根残体输入。** `[root_residue]` 按成对的日期、C 和 N 数量构建管理事件，沿当前 Jackson `vegetation.root.RAI` 归一化剖面分配，以 `litter_root_fractions` 写入已有根残体 AOM 组分。C/N 分别守恒，TAN 为零；输入不直接增加 NH4。`litter_input=false` 仅关闭活植物自动凋落物，不阻止已输入 AOM 的后续分解。指定根事件要求土壤碳过程开启、Jackson 根模式及 PlantCN/自动凋落物关闭，防止同一来源重复归还。

指定根 C/N 是土壤控制体外源，计入 `input_root_residue_C_g_cm2` / `input_root_residue_N_g_cm2`，并进入外源总账；它不计为 PlantCN 内部 `input_litter`，也不重复计入肥料或秸秆。事件应用标志只随接受态提交，失败重试和重启不得重复添加。完整管理日程、归一化 RAI 和组分比例进入根事件重启合同；不能在旧检查点上静默增加、删除或改写该输入。无根事件的原运行保留原兼容路径。长武本次采用工作簿数量和用户指定的每年6月25日代表日，详见[站点来源记录](../../../data/sites/changwu/PARAMETER_PROVENANCE.md)；该输入合同不等于 NH4 拟合已改善。

`soil.aom.advanceAOM` 按 `litter_component_rates_1d`、`k_manure_1d`、`k_straw_1d` 及 `doc_leach_1d` 逐步释放颗粒 C/N 和 DOC/DON。颗粒碳按 `input_fraction(1:2)` 归一化后进入 POM1/POM2；N 足够时先以 `CN_POM2` 支付 POM2，剩余进入 PON1，N 不足时退回颗粒碳比例分氮。无额外 DIN 借款，供体 N 与 PON1/PON2 增量在机器精度内守恒。这一路由不再用 `input_cn_lignin_to_labile` 固定输入 C:N 比；该键仅保留给显式调用的独立源输入适配器。

SOC 观测算子排除未反应 AOM，因此投放本身不再造成直接 SOC/DOC 跳增。同一个小时内仍允许按实际 `dt` 发生 AOM 分解、DOM 运移和 MEND 反应；不要求小时末 SOC 完全不变。完整有机碳库存始终包括 AOM，不能为了消除观测曲线阶跃而漏记输入。AOM 与 MEND 不重复加入源模型均匀输入。

## 四、根系和微生物怎样分配氮？

当前采用**先为根系预留，再供微生物利用**的顺序。预留给根系的氮不能再次提供给微生物。

微生物计算需要区分：

- **溶液中的可利用浓度**：决定吸氮有多快。
- **扣除根系预留后的可用库存**：限制实际最多能吸收多少。

例如，土壤中含有吸附态铵，不代表它们都可以作为溶液浓度参与速率计算。微生物吸收的氮必须从无机库扣除，矿化释放的氮必须返回无机库。

植物竞争由COMPASS负责后，耦合公式去掉了MEND原有的植物竞争分母项。这是明确的处理差异，不等于只把MEND植物吸氮量设为零。

当前COMPASS没有独立的亚硝酸盐状态，因此相关酶分配使用它实际计算的铵和硝酸盐。其他无机氮反应仍使用COMPASS的实现。

`mend_cn_mb_min`、`mend_cn_mb_max` 控制源小时反应的微生物 C:N 上下界；`mend_cn_enzp`、`mend_cn_enzm` 控制酶合成/周转与胞内酶三相的成对 C/N 转移。当前适配要求两类酶 C:N 相等。独立历史夹具缺少这些字段时沿用源值 2、14、3；正式参数从站点读取，并写入重启兼容性签名。

## 五、氧气不足时怎样处理？

当前生产先计算 MEND 一小时反应，`oxygenScale=1`，再以同一小时呼吸源汇重放氧气区间。供氧不可行时抛出 `soil:nitrogen:oxygenSourceInfeasible`，该小时不提交；不通过氧气缩减系数改变 MEND 方程。旧公共氧缩减策略属于历史耦合选择，已不用于当前生产路径。该说明不代表模型包含所有真实缺氧生理过程。

## 六、不同土层之间怎样交换物质？

正式模型保留两类有机物运输：

- 动态模式仅以 D/DON 库存求可输运浓度 `Cwater=D/theta`，向对流–弥散核传入 `Kd=0`；运输结束加回原逐层 Q/QON，吸附库不移动、不重分相。这里是源默认 MM 分支的输运接口，不把论文的 potential DOC 自动等同于某种实验提取量。零液水而 D>0 明确拒绝，不加隐式水量下限或强迫吸附。
- DOM 每个外层步使用与 DIN 相同的接受子步时间加权平均 `QL`、外层末液态 `thetaElement`、平均 `water.QMB` 及顶部 `QL(end)`。有限体积内部继续按不大于 `transport_substep_s = 300 s` 的正性子步推进。保留 MEND 单元库存的守恒有限体积离散，不改动无机氮的节点有限元或吸附方程。长武实际网格由 `domain.NL` 决定（当前为 58 个计算单元）。
- 微生物及携带的 C/N 仍支持一致的移动、附着和滞留运输，但长武基线 `microbial_transport = false`，因相关速率未率定。禁用运移不删除初始三相，也不禁止同相内反应。其他站点显式启用时继续重放接受水子步驱动，标签使用相同冻结运输账本。

层内的吸附、脱附或附着状态转换不应增加总量。同一份有机物也不能在溶解库和吸附库中重复统计；酶携带的碳氮应计入总库存。

**100厘米在5米土柱中是内部界面，不是正式的封闭底边界。** 关闭该界面的试验只用于查明运移影响，正式设置不因此关闭它。

DOC/DON 顶底边界按无机氮的 Type 1/2/3 编号约定配置。长武为 `doc_top = don_top = 2`（给定入流水相浓度，蒸发不携带非挥发性溶质），`doc_bottom = don_bottom = 3`（自由排水、零梯度对流流出，无外部溶质流入）。Type 1 为给定水相浓度；底部 Type 2 为给定入流浓度及零梯度出流。边界水通量直接读取水过程的外层平均，不用单元中心 QL 替代底部 QMB；当前物理开底支持液态自由排水。所有方向的 C/N 输入输出分别进入接受态累计账本；整柱不再描述为有机物零通量封闭。

以上路由、DOM 时间层、pH 选择与 C:N 参数均进入重启兼容性签名。旧直接输入路径或旧 DOM 水驱动的检查点不能静默续跑为新轨迹。现有 `1e-10`、`1e-12`、`1e-14` 守恒门不放宽，负库存不能靠截零掩盖。

## 七、怎样判断耦合结果是否正确？

本次MEND参考把0–100厘米作为一个整体反应箱，没有向下一土层运输的过程。COMPASS有多个土层，各层环境不同，上部物质还能进入更深处。因此，耦合结果不必与源模型重合。

判断时应检查：

1. 比较的深度范围、初态、输入和时段是否一致。
2. 库存变化有多少来自反应，有多少来自外部输入或跨层运输。
3. 离开某个库或土层的物质，是否在其他库、其他土层或输出中找到对应去向。

在相同源条件下，反应部分应复现MEND；恢复实际耦合条件后，应检查守恒和差异原因，不靠调参数强行追平源结果。

## 八、这份约定确认了什么？

本次确认保留 COMPASS 根竞争、无机氮方程、源汇式氧约束和正常层间运输；D/Q 恢复源动力学及独立先验，保留已有的负库存拒绝及节点氮库存约束。休眠直接补回和100厘米有机隔离仅用于诊断，不加入正式模型。

正式版本还需要在同一份源码和配置上完成组合运行、全年、重启与失败恢复检查。接口说明完成，不等于全部发布验收已经完成。

详细测试结果见[耦合验收表](../../model_comparison/MEND_ACCEPTANCE.md)。需要修改代码时，再查阅[实现位置补充](MEND_INTERFACE_IMPLEMENTATION_NOTES.md)。

## 九、DOC/DON 浓度、库存与参数单位

2026-10-09，Wenjie Liu：明确接受态输出与反应接口的不同单位。

- `doc_aqueous_concentration_profile` 和 `don_aqueous_concentration_profile`
  分别输出 mg C/L 水、mg N/L 水。动态模式由独立 D/DON 和液态含水量
  经 `soil.dom.phaseState` 计算，不使用 Kd。二者与无机氮水相浓度采用相同的
  浓度基准，不是额外的预报状态或库存。
- 原 `doc_carbon_profile`、`don_nitrogen_profile` 仍是溶解相的
  g 元素/cm³ 土库存；`qoc_carbon_profile`、`qon_nitrogen_profile` 是吸附相。
  不能把这些库存输出直接当成水样的 mg/L。
- MEND 内核底物使用 mg 元素/g 干土。均匀层的对应关系为
  `dissolved_mg_g = theta_liquid * aqueous_mg_L / (1000 * bulk_density_g_cm3)`。
  水相浓度输出直接使用分相结果，不从库存再次除以可能为零的含水量。
- 当前半饱和参数明确按 mg/g 先验使用，数值不因这次非负性和输出修复而改变。
  原始 MEND 文件的 mg/cm³ 标注与论文/部分源码的 mg/g 标注存在冲突；
  当前数值不应被描述为已经证明等价的体积到质量单位迁移。若另行确认参数
  来自体积口径，半饱和常数应除以容重，不能对速率与无量纲比例作相同换算。

DOC/DON 接受态必须非负。供体耗尽时，伴随氮转移必须等于供体可用氮，
并用同一实际转移量更新供体、受体及账本。守恒残差的浮点容差不授权保存
负库存；真实超支必须拒绝候选，不通过截零或放宽检查掩盖。

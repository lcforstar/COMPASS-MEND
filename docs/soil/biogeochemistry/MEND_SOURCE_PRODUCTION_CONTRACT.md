# COMPASS如何接入MEND的有机碳氮与微生物过程

更新日期：2026年9月15日。

本文说明MEND和COMPASS各自负责什么、每小时如何交换信息，以及正式耦合采用哪些处理。它是开发和使用模型时共同遵守的接口约定。测试结果放在单独的验收文档中。

## 一、MEND负责什么，COMPASS负责什么？

接入的是MEND的**有机碳氮与微生物反应部分**。土壤水分、温度、氧气、无机氮、根系和层间运输仍由COMPASS计算。

| 要解决的问题 | 由谁负责 |
|---|---|
| 每层土壤有多湿、多热，能获得多少氧气？ | COMPASS |
| 外界有多少碳氮进入土壤，进入什么深度？ | COMPASS的输入、植被和管理过程 |
| 有机质如何分解，微生物如何生长、呼吸和休眠？ | 接入COMPASS的MEND反应部分 |
| 微生物吸收多少无机氮、释放多少氮？ | MEND计算反应需求与释放，COMPASS提供并约束可用库存 |
| 无机氮如何硝化、反硝化、吸附和迁移？ | COMPASS |
| 溶解有机物和微生物如何在土层间移动？ | COMPASS |

也就是说，MEND计算每层土壤内的生物化学反应，COMPASS提供反应环境，并把不同土层和其他过程连接起来。

## 二、每小时怎样计算？

1. **准备环境和输入。** COMPASS计算本小时的土壤环境，根据已开启的过程准备施肥、凋落物等输入，再计算溶解有机物的层间运输。
2. **分配可用氮。** 先为根系预留氮，再确定微生物可利用的浓度和库存。
3. **计算有机反应。** MEND计算各层有机库、微生物和酶的变化，以及呼吸和氮的吸收释放。
4. **检查氧气和运输。** COMPASS根据实际供氧约束反应量，计算微生物运输、无机氮反应，并检查最终氧气是否够用；不足时重新计算。
5. **通过检查后一起保存。** 整个小时计算成功后，碳、氮、氧和土壤状态才一起更新。失败时退回小时初状态，不重复施肥、不重复扣氮、不推进时间。

当前MEND反应按一小时更新一次。水热计算即使在一小时内分成多个小步，也不能重复执行整小时的生物反应。

断点还需要保存会影响下一小时的运行记忆。目前明确包括上一小时已接受的根系吸水通量；只保存碳氮库和土壤状态并不足以保证重启一致。缺少这项记录的旧断点必须标明无法保证精确续跑。

## 三、初始碳氮和外部输入怎样处理？

**DOC/DON吸附采用COMPASS平衡关系（2026-09-16用户指定）。** 各层DOC和DON分别使用`soil.csv`的Kd，由总量、液态含水量和容重求水相/吸附相。接受态只保存总量；运输和反应读取平衡分相。耦合时关闭MEND动力学吸附，避免同一份物质使用两套吸附机制。显式小时反应读取反应开始时的水相底物，更新总量后重新分相。具体实现与验收见[平衡吸附说明](../../model_comparison/MEND_EQUILIBRIUM_SORPTION.md)。

**正式站点运行使用站点配置中的分层初始有机库。** 当前长武的分库包含先验假设，不应称为逐层实测。也不能为了对齐MEND，把上部土层的平均含量自动复制到整根5米土柱。

外部输入由COMPASS统一处理。必须明确每次输入的碳氮数量、进入的库、施加深度和时间，且每一份物质只计入一次。例如，COMPASS已经加入一份肥料后，MEND不能再加入同一份肥料；肥料中的铵态氮和有机氮也要分开计算。

这里要区分两种时序：

- 正式COMPASS路径在调用微生物反应前，由上游过程准备输入。
- 独立MEND对照按照源模型的小时末输入顺序运行。

此前对齐源小时末输入的试验程序，没有自动成为正式模型的输入功能。

AOM指新鲜加入、尚未完成分解的有机物，例如粪肥或秸秆。正式路径先由COMPASS输入和AOM过程准备物质，再交给MEND反应，不重复加入源模型的均匀输入。开关由站点配置和运行设置决定；恢复进度及验证范围见[候选基线说明](../../model_comparison/MEND_COUPLED_CANDIDATE.md)，本文只规定接口处理。

## 四、根系和微生物怎样分配氮？

当前采用**先为根系预留，再供微生物利用**的顺序。预留给根系的氮不能再次提供给微生物。

微生物计算需要区分：

- **溶液中的可利用浓度**：决定吸氮有多快。
- **扣除根系预留后的可用库存**：限制实际最多能吸收多少。

例如，土壤中含有吸附态铵，不代表它们都可以作为溶液浓度参与速率计算。微生物吸收的氮必须从无机库扣除，矿化释放的氮必须返回无机库。

植物竞争由COMPASS负责后，耦合公式去掉了MEND原有的植物竞争分母项。这是明确的处理差异，不等于只把MEND植物吸氮量设为零。

当前COMPASS没有独立的亚硝酸盐状态，因此相关酶分配使用它实际计算的铵和硝酸盐。其他无机氮反应仍使用COMPASS的实现。

## 五、氧气不足时怎样处理？

**先计算MEND的一小时反应量，再根据实际供氧，对这套碳氮反应量使用相同的缩减比例。**

例如，最终允许的反应比例为一半，本次MEND反应产生的碳氮变化、呼吸和氮交换量也按一半计入。这个比例同样作用于活跃与休眠之间的转换，不只作用于呼吸。

这样处理是为了让同一次反应中的碳、氮和耗氧保持一致。它不会把已进入土壤的外部肥料或有机物凭空减掉。

正式版本保留这个处理。此前让“休眠恢复为活跃”不受同样限制的试验，会改变恢复与代谢的相对速率，因此不采用。

这一做法通过了现有守恒检查，但仍是一种缺氧耦合假设，不能据此声称所有真实缺氧生理过程都已得到验证。

## 六、不同土层之间怎样交换物质？

正式模型保留两类有机物运输：

- 溶解有机碳和氮随水流、扩散和弥散在土层间移动。吸附部分不直接随水移动。
- 微生物及其携带的碳氮按COMPASS的移动、附着和滞留设置处理。碳和氮使用一致的运输规则，不能搬走微生物碳却把对应氮留在原层。

层内的吸附、脱附或附着状态转换不应增加总量。同一份有机物也不能在溶解库和吸附库中重复统计；酶携带的碳氮应计入总库存。

**100厘米在5米土柱中是内部界面，不是正式的封闭底边界。** 关闭该界面的试验只用于查明运移影响，正式设置不因此关闭它。

当前有机运输算子在整柱顶部和底部采用零通量，外部有机输入则单独加入。水、氧气、其他气体和无机氮各有自己的边界，所以不能把整根土柱称为对所有物质完全封闭。

## 七、怎样判断耦合结果是否正确？

本次MEND参考把0–100厘米作为一个整体反应箱，没有向下一土层运输的过程。COMPASS有多个土层，各层环境不同，上部物质还能进入更深处。因此，耦合结果不必与源模型重合。

判断时应检查：

1. 比较的深度范围、初态、输入和时段是否一致。
2. 库存变化有多少来自反应，有多少来自外部输入或跨层运输。
3. 离开某个库或土层的物质，是否在其他库、其他土层或输出中找到对应去向。

在相同源条件下，反应部分应复现MEND；恢复实际耦合条件后，应检查守恒和差异原因，不靠调参数强行追平源结果。

## 八、这份约定确认了什么？

本次确认保留COMPASS的根竞争、无机氮处理、公共氧缩减和正常层间运输，保留已修复的负库存及节点氮超支处理。休眠直接补回和100厘米有机隔离仅用于诊断，不加入正式模型。

正式版本还需要在同一份源码和配置上完成组合运行、全年、重启与失败恢复检查。接口说明完成，不等于全部发布验收已经完成。

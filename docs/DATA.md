# 运行数据与输出

本包保留接受基线所需的站点输入及静态模型资源。数值和原始测定/强迫说明应一同保存，不以重命名文件或更换运行年份重标观测日期。

## 随包数据

| 目录 | 当前清点 | 用途 |
|---|---:|---|
| `data/model_library_nc/` | 37个文件，约42.55 MiB | 35个NC资源文件及清单CSV、说明MD，供静态光学、土壤光谱和大气传输等使用 |
| `data/sites/changwu/` | 24个文件，约2.37 MiB | 接受的配置、土壤参数、初值、气象强迫、边界和站点观测 |
| `data/global/` | 3个文件，约0.32 MiB | 可选区域聚集指数资料；当前长武点模拟不读取该全球网格 |

上述清点未发现单文件超过50 MB。`model_library_nc/nc_manifest.csv`保留原资源与NetCDF对应关系；资源格式转换不构成新的数据授权。

## 长武站点文件

- `site.toml`：计算时段、过程开关、管理事件、全局MEND设置与输出目录。
- `soil.csv`：18个参数采样深度、40列；11个MEND分层列的单位在表头/说明中保留。Qmax、Kba、Kdes_ref已迁入soil，TOML中不再重复定义。
- `soil_initial_profile.csv`、`organic_initial_pools.csv`：物理初态与独立有机C/N初始分配。
- `forcing.csv`、`canopy_measurements.csv`、`water_boundary.csv`、`root.csv`：当前驱动与边界/根系资料。
- 原始观测工作簿、其他强迫期、参照剖面和站点附属文件随站点包保留，不据文件存在推断它们都被当前8760步逐一读取。
- `PARAMETER_PROVENANCE.md`与`doc_initial_2006_proxy.json`：参数沿革、观测日期与跨年初始化/参照说明。

详细初始表的 `frac_*` 表示各主C库占总SOC-C的比例；`nfrac_*`表示N库质量除以总SOC-C（g N/g SOC-C），不是各N库占总N，不能要求其和为1。MB/BD/ENZN内部相分配不应再算作额外主SOC库。

用户观测和forcing作为本地运行/复现输入予以保留；公开分发权应按各材料的来源与已有授权核实。对外发布时保留原始单位、日期及必要来源信息。

## 可再生输出

默认结果写到 `data/output/changwu/`，日志位于 `logs/`子目录。启动sidecar记录启动配置，不作为科学结果或验证通过凭证。

源码版本控制忽略运行输出、日志、检查点、verification历史、终端截图、临时站点、工作缓存和私人控制器。必需的模型库与接受站点不能因沿用旧忽略规则而从可运行包中漏掉。

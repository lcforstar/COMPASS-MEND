# DOC/DON改用平衡吸附

2026-09-16，按用户要求，长武正式配置采用`dom.sorption_model = "linear_equilibrium"`。先前`compass-mend-rc1-20260916`归档保留为动力学吸附的历史对照，不覆盖其文件或将其验收结论移用于本次改动。

## 当前计算方式

DOC和DON分别使用`soil.csv`中的Kd剖面：

`总量 = (液态体积含水量 + 容重 × Kd) × 水相浓度`。

总量单位g/cm³土，水相浓度g/cm³水，容重g/cm³，Kd为cm³/g。DOC、DON可有不同Kd。接受态只保存各自总量，水相和吸附相由当前总量、含水量、容重和Kd即时计算，不再保存独立动力学吸附库。

输入和运输更新总量后，反应从平衡分相中读取可利用底物。保留MEND原来的显式小时反应顺序：本小时摄取速率及供体上限由反应开始时的水相库存计算，反应后再按新的总量平衡分相；并未改为小时内连续隐式反应求解。DOM运输本身在各运输子步使用平衡浓度和储量容量。

MEND核中的吸附、解吸速率在平衡耦合适配器中置零。原始独立MEND小时核未修改，仍可用于源代码复现。平衡模式下`mend_qmax_mg_g`、`mend_kba_g_mg`、`mend_kdes_mg_g_h`不控制吸附，不应作为本模式的吸附率定参数；它们保留用于显式选择动力学模式的参考运行。

碳氮反应先按供氧限制共同缩放，再恢复平衡分相。平衡分相不是耗氧反应，不随氧限制额外关闭。其相间重分配账本单独记录，不冒充MEND动力学吸附通量。

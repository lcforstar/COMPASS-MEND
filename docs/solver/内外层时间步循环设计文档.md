# 内外层时间步循环设计文档

**版本**: 1.0 (设计阶段)  
**日期**: 2026-04-29  
**作者**: 模型开发团队  
**状态**: 待 v1.0 完成后实施

---

## 1. 背景与目标

### 现状（v1.0）
- **外层步**: 固定 `Delt_t_outer`（对齐强迫/输出，如 30min 或 1hour）
- **内层**:  固定 KIT 迭代次数 `NIT`，每次迭代用相同步长 `Delt_t = Delt_t_outer`
- **问题**: 当 PDE 系统不收敛时，模型只打印警告继续，可能积累误差

### 目标（v2.0+）
实现**内层变步长子循环**：
- 若 KIT 不收敛 → 自动减半内层步长 → 重新求解
- 若 KIT 收敛 → 允许放大内层步长（加速下一步）
- 外层步保持固定，对强迫和输出透明
- 逐小时（或固定频率）输出，通量按时间加权累积

## 2. 新架构设计

### 2.1 整体流程

```
外层循环 KT (for loop, 固定步 Delt_t_outer)
├── 强迫数据读取（固定，对应 KT 时刻）
├── SCOPE 能量平衡计算（可选，跨内层）
│
└── 【新增】内层子循环
    ├── 初始化:
    │   ├── t_elapsed_inner = 0  [s]
    │   ├── Delt_t_inner = Delt_t_outer
    │   └── 通量累积器清零: Q_water=0, Q_heat=0, ...
    │
    └── while t_elapsed_inner < Delt_t_outer
        │
        ├── 【新增】保存状态快照
        │   └── SoilVar_bak = SoilVariables  (hh, TT, P_g, etc)
        │
        ├── KIT 迭代求解 (NIT 次或收敛)
        │   └── 输入: Delt_t_inner
        │
        ├── 收敛判据
        │   │
        │   ├─【是】→ 接受
        │   │   ├── t_elapsed_inner += Delt_t_inner
        │   │   ├── 【新增】累积通量: Q_water += flux × Delt_t_inner
        │   │   ├── 【新增】可选: Delt_t_inner *= 1.5 (加速)
        │   │   └── 确保不超外层步: Delt_t_inner = min(Delt_t_inner, Delt_t_outer - t_elapsed_inner)
        │   │
        │   └─【否】→ 拒绝
        │       ├── 【新增】恢复快照: SoilVariables = SoilVar_bak
        │       ├── Delt_t_inner /= 2  (缩小重试)
        │       └── if Delt_t_inner < Delt_t_min → 报错/降级处理
        │
        └── t_elapsed_inner >= Delt_t_outer 时退出
│
├── 【修改】通量输出
│   └── 输出累积/平均: ET_out = Q_ET_accum / Delt_t_outer (if 需要速率)
│       或直接输出累积: ET_accum = Q_ET_accum (单位: mm/hour)
│
└── 继续下一个外层步
```

### 2.2 外层步与强迫

- **外层步固定**: `Delt_t_outer = cfg.Time.Delt_t` (如 1800s, 3600s)
- **强迫同步**: 每个外层步读一组强迫 (Ta, RH, Precip, Radiation 等)
- **内层重复用**: 内层每个子步用相同强迫值（物理合理：1小时内气象条件视为常数）

## 3. 关键实现细节

### 3.1 状态快照与恢复

```matlab
% 需要备份的状态向量（SoilVariables 中）
% - hh        : 基质势 [cm]
% - TT        : 温度 [K]
% - theta     : 体积含水量 [m³/m³]
% - P_g       : 气压 [Pa]
% - P_gg      : 干空气分压 [Pa] (if 气体)
% 以及其他累积变量 (SAVE, AirVars, etc.)

% 备份方式: 深拷贝
SoilVar_backup = struct();
SoilVar_backup.hh   = SoilVariables.hh;
SoilVar_backup.TT   = SoilVariables.TT;
SoilVar_backup.theta = SoilVariables.theta;
% ... 其他关键字段

% 恢复: 逐字段复制（不建议结构体直接赋值，避免引用问题）
SoilVariables.hh   = SoilVar_backup.hh;
SoilVariables.TT   = SoilVar_backup.TT;
SoilVariables.theta = SoilVar_backup.theta;
```

### 3.2 通量累积

```matlab
% 在 AMainloop.m 主循环的内层前初始化（每个 KT）
Q_ET_accum      = 0;      % 累积蒸散 [mm]
Q_inf_accum     = 0;      % 累积入渗 [mm]
Q_heat_top_accum = 0;     % 累积地表热通量 [W]
% ... 其他通量

% 内层循环内，每次 KIT 收敛后累积
Q_ET_accum      += EVAP(KT) * Delt_t_inner / 1000;  % 单位转换
Q_inf_accum     += Infiltration * Delt_t_inner / 1000;
Q_heat_top_accum += HBoundaryFlux(1) * Delt_t_inner;
% ... 其他通量

% 外层步结束，输出累积值
Output.ET(KT)       = Q_ET_accum;           % mm/hour (if Delt_t_outer=3600s)
Output.Infiltration(KT) = Q_inf_accum;
Output.Heat(KT)     = Q_heat_top_accum;    % J/m²
```

**状态变量不累积**：h, T, P_g 等在内层循环结束时自动是正确的外层步值，直接输出。

### 3.3 内层步长策略

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `Delt_t_init` | = `Delt_t_outer` | 内层初始步长（外层步大小） |
| `Delt_t_min` | = `Delt_t_outer / 64` | 最小可接受步长（防止无限缩小） |
| `Delt_t_max` | = `Delt_t_outer` | 最大步长（不超外层） |
| `growth_factor` | 1.5 | 收敛时的放大系数 |
| `shrink_factor` | 0.5 | 不收敛时的缩小系数 |

### 3.4 收敛判据

沿用现有 KIT 收敛条件（不动）：
```matlab
if (Error_Water < threshold_water) && (Error_Energy < threshold_energy)
    % 收敛
else
    % 不收敛
end
```

## 4. 代码框架

### 4.1 AMainloop.m 中的修改位置

**当前（v1.0）**:
```matlab
% line 589-865
for KIT = 1:NIT
    % 求解 PDE
    % 检查收敛
end
if ~StepConverged
    fprintf('[NONCONVERGED] ...\n');
end
```

**新增（v2.0）**:
```matlab
% line 589 前添加
Q_ET_accum = 0;
Q_inf_accum = 0;
% ... 其他通量

% line 589-865 替换为内层子循环
t_elapsed_inner = 0;
Delt_t_inner = Delt_t_outer;

while t_elapsed_inner < Delt_t_outer
    % 备份状态
    SoilVar_bak = backup_state(SoilVariables);
    
    % KIT 求解
    for KIT = 1:NIT
        % ... PDE 求解 (用 Delt_t_inner 代替 Delt_t_outer)
    end
    
    % 检查收敛
    if StepConverged
        % 接受
        t_elapsed_inner = t_elapsed_inner + Delt_t_inner;
        
        % 累积通量
        Q_ET_accum = Q_ET_accum + EVAP(KT) * Delt_t_inner / 1000;
        
        % 放大步长（可选）
        Delt_t_inner = min(Delt_t_inner * 1.5, Delt_t_outer - t_elapsed_inner);
    else
        % 拒绝，恢复
        SoilVariables = restore_state(SoilVar_bak);
        Delt_t_inner = Delt_t_inner / 2;
        
        if Delt_t_inner < Delt_t_min
            warning('Min step reached, forced acceptance');
            t_elapsed_inner = t_elapsed_inner + Delt_t_min;
            break;
        end
    end
end

% 输出通量
% Output.ET(KT) = Q_ET_accum;
% 状态变量 h, T, P_g 已在内层循环结束时正确，直接使用
```

### 4.2 辅助函数

```matlab
function backup = backup_state(SoilVariables)
    backup.hh   = SoilVariables.hh;
    backup.TT   = SoilVariables.TT;
    backup.theta = SoilVariables.theta;
    backup.P_g  = SoilVariables.P_g;
    backup.P_gg = SoilVariables.P_gg;
    % ... 其他可能需要的字段
end

function SoilVariables = restore_state(SoilVariables, backup)
    SoilVariables.hh   = backup.hh;
    SoilVariables.TT   = backup.TT;
    SoilVariables.theta = backup.theta;
    SoilVariables.P_g  = backup.P_g;
    SoilVariables.P_gg = backup.P_gg;
end
```

## 5. 物理与数值考虑

### 5.1 强迫处理
- **气象强迫**: 一小时内视为常数，无需内层分割
  - Ta、RH、风速 → 瞬时值，直接用
  - 辐射 [W/m²]、降水速率 [mm/s] → 速率，自动乘 dt 积分
- **无需缩放**: PDE 矩阵组装时已包含 `Delt_t`，用户只传值

### 5.2 通量守恒
- **关键**: 通量必须按时间加权累积
  - `Q = Σ(flux_i × Δt_i)` 
  - 外层步后输出累积值或平均速率
- **状态变量**: h, T, P_g 等时间进度自动正确，无需处理

### 5.3 数值稳定性
- **初始步长**: 从 `Delt_t_outer` 开始，逐次减半，确保收敛
- **最小步长**: 防止无限细分，建议 `Delt_t_outer / 64` 或更粗
- **放大策略**: 仅在连续收敛的情况下尝试，否则保守

| 指标 | 说明 |
|------|------|
| **数值精度** | 变步长追踪收敛性，不收敛自动细分 → 精度更高 |
